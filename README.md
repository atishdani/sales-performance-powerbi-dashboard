# Retail Sales Performance Dashboard

## Tools
Power BI, DAX, Data Modelling, Excel

## Description
Developed an interactive Power BI dashboard analysing ₹438K revenue across 5,600+ transactions to identify sales trends, product performance, and revenue concentration.

## Key Features
- KPI tracking dashboard
- Product-level sales analysis
- Category performance insights
- Revenue trend visualisation
- Interactive filters & slicers

## Insights
- Identified 67% revenue concentration in few product categories
- Highlighted top-performing products
- Improved reporting efficiency

## Skills Used
Power BI, DAX, Data Visualisation, KPI Reporting, Data Analysis
